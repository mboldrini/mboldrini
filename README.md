### Projects

**[Local AI Transcriber](https://github.com/mboldrini/AudioTranscript)** — offline speech-to-text for audio and video files using faster-whisper. No API keys, no usage costs, nothing leaves the machine. Has a Windows 95-style UI, downloads from YouTube and Instagram via yt-dlp, runs on GPU with CPU fallback, and exports to `.md`, `.srt`, and `.vtt`. Built with Python and Flask.

**[PrDashboard](https://github.com/mboldrini/G-Hub)** — local dashboard for tracking GitHub pull requests across multiple repos, built in C# (.NET 8). Born from a real frustration: working across many repos at once, GitHub never gave me the consolidated view I needed. Ships as a self-contained `.exe`, runs on localhost, auto-refreshes, sends audio notifications for new comments and CI failures, and generates Markdown standup reports.

**[SayIt](https://sayit.mboldrini.com/)** — PWA for training English pronunciation, built with React 19 and Vite. Uses the Web Speech API for real-time voice recognition and instant scoring. 40 exercises covering tongue twisters, word stress, daily phrases, and articulation drills. No backend, no account, installable on Android.
